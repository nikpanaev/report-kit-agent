# Проверка Report Kit на Windows

Проверку на настоящем Windows выполняет пользователь. Здесь подготовлены код и локальные тесты; работа на Windows пока не подтверждена. Установку и подключение аккаунтов начинаем после отдельного разрешения. Принятые отчёты повторять не нужно.

После разрешённой установки запустите предлагаемую приложением настройку. Агент начнёт проверку сам. Для отдельной проверки Windows можно написать:

> Помоги проверить Report Kit на Windows. Сначала проверь приложение, доступные инструменты и рабочую папку. Затем пройдём подключение LiveDune, API, сайт, выгрузку Excel и работу после перезапуска. Ключи в чат не проси. Отчёты клиентов пока не запускай.

**Сначала — рабочая папка.** Агент проверит версии и права, подготовит отдельную папку и выполнит местную проверку. Если приложение или компания запрещает действие, агент объяснит ограничение. Отключать защиту или давать полный доступ для проверки не нужно.

Агент также проверит восстановление общей очереди на отдельном местном примере: завершит только собственный проверочный процесс и убедится, что чужая или ещё работающая задача сохраняет очередь. Соцсети и клиентские отчёты для этого не открываются. Если приложение запрещает такую проверку, результат останется «не проверено».

**Затем — ваш LiveDune.** Вы входите на сайт сами. Если API доступен вашему аккаунту, агент поможет сохранить ключ в системном Диспетчере учётных данных. Ключ вводится только в системное поле пароля. В чат его присылать не надо. Проверка чтения ключа сообщает только, что он доступен.

**После этого — данные и сайт.** Агент уточнит сообщество, период и небольшой лимит запросов, получит показатель через API, откроет тот же период на сайте и скачает Excel. Если браузером нельзя управлять, предложит скачать файл самостоятельно и отметит это ограничение. Посмотрите, что выбран правильный источник и период, таблица открывается, а снимки читаются.

**Последний шаг — перезапуск.** Перезапустите приложение и попросите продолжить проверку. Агент проверит, что ключ и рабочая папка доступны. Повторно запрашивать статистику только ради перезапуска не требуется.

В конце агент покажет четыре отдельных результата: доступ к ключу и файлам, API, сайт или ручная выгрузка, работа после перезапуска. Подтвердите, что получилось, или опишите ошибку простыми словами. Все подробности агент сохранит сам; ключ, личные данные и полный технический журнал отправлять не нужно.

Эта проверка относится к LiveDune и рабочей папке. Google, другие соцсети, первый клиентский отчёт, обновление и откат проверяются отдельными шагами по необходимости.

## Проверка среды и поддержки

На компьютере без Python агент сам готовит нужные компоненты после разрешения. Не устанавливайте Python или библиотеки вручную. Если для задачи нужен браузер Playwright, дождитесь объяснения и подтвердите его подготовку. Обычный Chrome не должен меняться.

После перезапуска убедитесь, что агент продолжает настройку с сохранённого шага. Попросите «Не работает. Подготовь файл для поддержки», затем проверьте запасной запуск двойным нажатием из папки поддержки при закрытом чате. Получается один ZIP; пересылаете его вы сами. Команды, ключи и полные журналы присылать не нужно.

Для этой проверки нужен Windows 11+ x64. Windows Server, Windows ARM, Linux и macOS Intel этой средой пока не поддерживаются. Отдельно подготовлен вариант macOS 14+ на Apple Silicon. Агент проверяет устройство до запуска компонентов; требования — [в документации Playwright](https://playwright.dev/python/docs/intro#system-requirements).
