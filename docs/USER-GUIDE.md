# Начните с одного сообщения

**«Помоги настроить Report Kit и сделать первый отчёт для моего клиента».**

Если приложение показывает список команд, начните с **«Report Kit / Настройка»**.

Агент проведёт вас по шагам. Не нужно заранее знать названия настроек, подключений или способов проверки. Если вы чего-то не знаете, напишите **«Не знаю, помоги выбрать»**.

Этот комплект пока готовится к выпуску. Установка на другом устройстве ещё не проверена. Агент должен сначала проверить, что доступно именно вам.

## Подготовка рабочего места

Агент выяснит, в каком приложении вы работаете, и проверит возможность читать материалы, сохранять файлы и работать с нужными сервисами. Этот комплект рассчитан на Codex с инструментами работы. Если ваш чат умеет только отвечать текстом, агент объяснит, какое приложение или подключение требуется, и поможет перейти к подходящему варианту. Одной ссылки в обычном текстовом чате недостаточно для самостоятельного создания файлов.

Сначала выберите папку для рабочих материалов. Агент предложит подходящий вариант и создаст её после вашего выбора, если это разрешено приложением. Клиентские файлы будут храниться отдельно от программы.

Если приложение покажет запрос разрешения, агент объяснит, что именно будет сделано и зачем. Разрешайте только понятное действие. Агент не должен предлагать доступ ко всему компьютеру как универсальное решение: он объяснит конкретное нужное разрешение. Если действие запрещено правилами вашей организации, агент сохранит работу и объяснит, с чем обратиться к ответственному сотруднику.

## Первый клиент: что понадобится

Агент спросит по очереди:

1. Как называется клиент?
2. Как должен выглядеть результат: презентация, текстовый документ или таблица? Если не знаете — предложите образец, агент поможет выбрать.
3. Есть ли пример отчёта? Пришлите ссылку или приложите файл. Подойдёт прежний отчёт клиента. Агент изучит его оформление, расчёты и связанные материалы.
4. За какой месяц и год нужен первый отчёт? Какие площадки включить?
5. Откуда брать данные? Это могут быть LiveDune, выгрузка, таблица модератора, почта или другие согласованные источники. Агент объяснит варианты по вашему образцу.
6. Где сохранить результат? Если папка клиента уже есть на Google Диске — пришлите ссылку. Если её нет, агент предложит создать её в выбранном вами месте.

Не нужно собирать всё заранее. Можно ответить на часть вопросов и продолжить позже. Уже данные ответы агент сохранит и повторно спрашивать их не будет.

Ссылки можно взять из адресной строки браузера, когда открыт нужный файл или папка. Доступ проверяется отдельно: если агент не может открыть файл, он подскажет следующий шаг. Не включайте общий доступ для всех ради такой проверки.

## Подключение Google и других сервисов

Для презентации используется Google Презентации, для текстового отчёта — Google Документы, для таблицы и данных графиков — Google Таблицы. Агент объяснит выбор по задаче и проверит нужное подключение Google. Если подключения нет, он проведёт вас через доступный способ его добавления.

Вы сами выбираете рабочий Google-аккаунт и входите в него в окне сервиса. Пароли, коды входа и секретные ключи в чат не отправляйте. Агент не получает доступ автоматически только потому, что вы дали ссылку.

LiveDune, соцсеть или почта подключаются тогда, когда нужны конкретному отчёту. Подключать всё сразу не требуется. Перед созданием каждого нового файла агент уточнит аккаунт; если вы уже выбрали его для этого создания, повторный вопрос не нужен.

## Первый отчёт и сохранение правил

Агент покажет понятный план, соберёт первый отчёт по образцу и проверит данные, оформление и ссылки. Вы получите ссылку на результат и конкретные ограничения, если часть работы выполнить не удалось.

Посмотрите отчёт и пришлите правки. Можно писать обычными словами: **«Эту таблицу выровнять»**, **«Такой вывод больше не использовать»**. Постоянные правила агент сохранит для следующих месяцев.

Когда всё подходит, напишите **«Отчёт принят»**. Затем агент подготовит отдельную основу для будущих отчётов и покажет её вам: **«Использовать эту основу в следующих отчётах?»**. Это отдельный выбор: принятый отчёт содержит данные месяца, а основа предназначена для следующих периодов.

После этого можно проверить ещё один выбранный вами период: так мы убедимся, что смена месяца работает правильно. Агент объяснит цель; вам не нужно знать термин «пилот». Без вашего поручения новый период не запускается. Для клиента можно создать отдельный чат после вашего согласия.

## Следующие отчёты

Напишите в чате клиента **«Сделай отчёт за сентябрь 2026»** и приложите новую выгрузку, если она нужна. Постоянные ссылки, оформление и правила уже сохранены. Для отчёта с историей нескольких месяцев уточните, какие месяцы добавить.

После приёмки агент убирает свои ненужные временные файлы. Ваши исходники, итоговые отчёты и необходимые материалы восстановления сохраняются. Принятие отчёта не разрешает автоматически отправить его клиенту.

## Если что-то не получается

Напишите **«Не получается, помоги»**. Агент сначала проверит причину и сам выполнит разрешённые действия. Если нужен ваш шаг, он даст короткую инструкцию: что открыть, что выбрать и какой результат должен появиться. Следующий шаг — после проверки предыдущего.

**«Пауза»** сохраняет место остановки. **«Продолжай»** возвращает к указанной работе. Обновление программы само по себе паузу не снимает.

## Обновления

При настройке агент предложит выбор: **«Применять совместимые обновления автоматически или каждый раз спрашивать вас?»**

Автоматический вариант относится только к проверенным версиям из выбранного источника. Перед заменой агент проверяет всех ваших клиентов, сохраняет прежнюю версию и работает между отчётами. Новые доступы, смена источника, изменение данных или несовместимость требуют отдельного решения. Выбор можно отозвать в любой момент: **«Спрашивай перед каждым обновлением»**.

Новые версии проверяются перед работой не чаще раза в сутки. Если сеть недоступна, сохраняется текущая версия. Для проверки без открытого чата потребуется отдельная доступная настройка расписания; агент предложит её только если ваше приложение это поддерживает. Пока это не настроено, работа при закрытом приложении не обещается.

Приложение может потребовать ваше подтверждение или перезапуск даже при выбранных автообновлениях. Агент объяснит один необходимый шаг и проверит, что новая версия действительно заработала. Если обновление не удалось, он использует сохранённый безопасный путь возврата; ваши отчёты и клиентские правила обновлением не перезаписываются.
