# Как работать с Report Kit

На Windows помощник покажет пояснение и полный текст условий, затем спросит, разрешаете ли вы подготовку и принимаете ли условия. Достаточно ответить «да». При отказе выполненные шаги сохранятся. Если условия не менялись, повторный вопрос не нужен. При возврате после неудачного обновления сохраняется и прежнее подтверждение. Visual Studio, Python и библиотеки вручную устанавливать не нужно.

Report Kit помогает готовить отчёты для клиентов: разбирает образец, собирает данные, оформляет результат и запоминает ваши правки для следующих месяцев.

Чтобы начать, откройте новый чат в Codex и напишите:

**«Хочу готовить отчёты с [Report Kit](https://github.com/nikpanaev/report-kit-agent). Подключи его и помоги настроить работу».** Помощник начнёт настройку и объяснит необходимые действия. Если Report Kit уже подключён, достаточно обычного обращения: незавершённые шаги он проверит сам.

Если в приложении есть список команд, выберите **«Report Kit / Настройка»**.

Подготовлен первый тестовый выпуск Report Kit с готовыми компонентами. Его установка и работа на компьютере сотрудника ещё требуют проверки. Локально проверены подготовка компонентов, сохранение шагов и сбор файла поддержки; среда запускалась на macOS. Установка через приложение, первый запуск у сотрудника и работа на Windows ещё не проверены. Описанный ниже порядок применяется после разрешённого подключения. Простое открытие ссылки не устанавливает Report Kit.

Первый тестовый вариант — Windows 11+ x64 или macOS 14+ на Apple Silicon. Другие варианты ОС и процессора этой поставкой пока не поддерживаются. Настоящую Windows проверит сотрудник по [короткому списку](WINDOWS-CHECK.md).

## Что нужно настроить

Чат, в котором вы начали установку, станет основным чатом **Report Kit**. Здесь вы будете подключать новых клиентов, готовить первые тестовые отчёты и решать общие вопросы. После успешной настройки помощник переименует этот же чат в «Report Kit», если приложение позволяет. Если это нужно сделать вручную, он объяснит нужное действие. Отдельный общий чат создавать не требуется.

После настройки помощник начнёт знакомство с первым клиентом: сначала спросит название, затем поможет выбрать формат и пример отчёта, уточнит период, данные и папку для результата. Он спрашивает по шагам и использует уже полученные ответы. Если готового примера нет, вместе согласуете структуру. Вам не нужно заранее знать весь список материалов или самостоятельно составлять задание.

Report Kit рассчитан на работу в Codex, где помощник может читать и создавать файлы и пользоваться нужными сервисами. В обычном чате, который умеет только отвечать текстом, он сможет помочь с текстом, но не собрать отчёт самостоятельно. Если возможностей вашего приложения недостаточно, помощник объяснит, что нужно подключить и как это сделать.

Сначала выберите папку для работы. Там будут храниться материалы клиентов, отчёты и сохранённые настройки. Они хранятся отдельно от файлов Report Kit, чтобы обновление программы их не затронуло.

Во время настройки приложение может попросить ваше разрешение. Помощник объяснит, зачем оно нужно и что произойдёт после подтверждения. Давать доступ ко всему компьютеру для решения любой проблемы не нужно. Если действие запрещено правилами вашей компании, работа остановится на этом шаге. Помощник сохранит сделанное и объяснит, с каким вопросом обратиться к ответственному сотруднику.

## Что прислать для первого отчёта

Лучше всего начать с прежнего отчёта клиента: приложить файл или дать ссылку. По нему проще понять, какие нужны разделы, данные и оформление.

Помощник спросит:

- как называется клиент;
- за какой месяц и год нужен отчёт;
- какие площадки включить;
- откуда брать данные: из LiveDune, вашей выгрузки, таблицы модератора, почты или другого источника;
- куда сохранить результат;
- на каком Google-аккаунте создать файл и кому дать доступ.

Если вы не знаете, нужен ли текстовый документ, таблица или презентация, пришлите образец — помощник предложит подходящий вариант. Обязательные разделы и правила расчётов он разберёт сам, а неясные места уточнит у вас.

Необязательно собирать всё сразу. Можно прислать то, что уже есть, и продолжить позже. Сохранённые ответы не придётся давать заново. Если в чём-то сомневаетесь, так и напишите: **«Не знаю, помоги выбрать»**.

Ссылку на отчёт или папку можно скопировать из адресной строки браузера. Если файл лежит на компьютере, приложите его к сообщению. Для чужого файла может понадобиться доступ от владельца. Открывать его всем в интернете ради проверки не нужно.

## Как подключаются сервисы

Для слайдов используются Google Презентации, для текста — Google Документы, для расчётов — Google Таблицы. Помощник проверит, подключён ли нужный Google-аккаунт, и при необходимости проведёт вас через настройку.

Сам вход вы выполняете в окне сервиса. Пароли, коды входа и секретные ключи в чат не отправляйте. Ссылка на файл сама по себе не даёт помощнику доступа к вашему Google Диску.

Подключать все сервисы заранее не требуется. LiveDune, почта и соцсети понадобятся только тогда, когда из них нужно получить данные для отчёта. Перед созданием нового файла помощник уточнит Google-аккаунт. Если вы уже выбрали его именно для этого файла, повторный вопрос не нужен.

## Как проходит первый отчёт

Помощник изучит образец, предложит план и после согласования соберёт отчёт. Затем проверит расчёты, оформление и ссылки. Вы получите ссылку на готовый файл. Если каких-то данных не хватило или часть работы выполнить не удалось, он прямо об этом скажет.

Посмотрите результат и напишите, что исправить. Например: **«Выровняй эту таблицу»**, **«Убери этот вывод»**, **«В следующих отчётах используй такие заголовки»**. Правила для следующих месяцев сохранятся.

Когда всё устраивает, напишите **«Отчёт принят»**.

Первый тестовый отчёт готовится в общем чате Report Kit. После его приёмки помощник сам предложит подготовить шаблоны и отдельного агента именно для этого клиента. Специально знать или просить об этой возможности заранее не нужно.

Шаблоны нужно посмотреть и подтвердить отдельно. Отчёт содержит данные конкретного месяца, а шаблоны нужны для следующих отчётов в том же виде. С вашего согласия помощник создаст отдельного агента в отдельном чате с названием клиента, например «Report Kit / Альфа», и передаст ему принятые правила, оформление, шаблоны и ссылки на источники. Основной чат «Report Kit» останется для подключения других клиентов и общих вопросов.

После этого следующие отчёты заказываются в чате клиента. Там же можно проверить работу на другом выбранном вами периоде. Новый отчёт запускается только по вашему поручению. Если приложение не позволяет создать чат автоматически, помощник объяснит, как открыть его вручную, и подготовит первое сообщение.

## Как делать следующие отчёты

В чате клиента напишите, например: **«Сделай отчёт за сентябрь 2026»**. Приложите новую выгрузку, если данные приходят из файла. Сохранённые ссылки, оформление и ваши правила будут использованы снова.

Если нужен накопительный отчёт, укажите, какие месяцы добавить. Уже принятые данные за прошлые периоды сохраняются.

После вашего подтверждения помощник удалит свои ненужные временные файлы. Ваши исходники, готовые отчёты и материалы, которые ещё нужны для восстановления работы, останутся. Отправка отчёта клиенту — отдельное действие: слова «отчёт принят» её не разрешают.

## Как остановиться и продолжить

Напишите **«Пауза»**, если работу нужно остановить. Чтобы вернуться к ней, напишите **«Продолжай»**. Помощник продолжит с сохранённого шага. Обновление Report Kit само по себе работу не возобновляет.

## Как устроены обновления

При настройке вы выбираете: разрешить подходящие обновления автоматически или подтверждать каждое из них.

Перед обновлением Report Kit проверяет, подходит ли новая версия всем вашим клиентам. Замена происходит между отчётами; прежняя версия сохраняется на случай возврата. Если обновлению нужны дополнительные права, другой источник или изменение хранимых данных, это согласуется отдельно. Несовместимая версия автоматически не устанавливается.

Свой выбор можно изменить: **«Спрашивай перед каждым обновлением»**.

Новые версии проверяются перед работой не чаще одного раза в сутки. Если нет интернета, остаётся текущая версия. При закрытом приложении Report Kit не проверяет обновления. Отдельное расписание сейчас не настроено.

Даже при разрешённых автообновлениях приложение может попросить подтверждение или перезапуск. Помощник объяснит, что сделать, и проверит результат. Если обновление не сработало, он проверит, можно ли безопасно вернуть прежнюю версию. Ваши отчёты и правила клиентов при этом сохраняются.

Если что-то не получается, напишите **«Помоги разобраться»**. Типовые ситуации разобраны в [справке](HELP.md).

## Одна ссылка и первая настройка

Вам передают одну ссылку — на **report-kit-agent**. После разрешённого подключения в Codex используйте доступное в приложении действие настройки либо отправьте первый обычный запрос в активный Report Kit. При первом обычном обращении агент сам проверит незавершённые шаги; специальная команда не нужна. В обычном текстовом чате такой возможности может не быть; помощник проверит это и подскажет следующий шаг.

До начала нужен доступ к этому приложению и интернет для первой загрузки. Для первого отчёта подготовьте прежний отчёт или образец, месяц и год, исходные файлы или ссылки на данные, ссылку на рабочую папку, если она уже есть. Если чего-то нет, скажите об этом: помощник поможет выбрать. Заранее подключать все сервисы не нужно.

Помощник сам найдёт и проверит нужные инструменты, подберёт совместимый комплект и подготовит настройку. Искать второй репозиторий, выбирать версии или вводить команды не требуется. Он предложит разрешить подходящие обновления автоматически. Этот выбор можно изменить позже.

Вам могут понадобиться только подтверждение установки в приложении, перезапуск и самостоятельный вход в нужный сервис. Помощник объяснит, зачем это нужно и куда нажать. Полный доступ ко всему компьютеру не требуется. Если не хватает разрешения вашей организации, он назовёт нужное действие, сохранив выполненные шаги.

Скачанные файлы ещё не означают, что инструменты установлены. Помощник проверит результат настройки отдельно. Если интернет пропал до первой загрузки, продолжит с сохранённого шага после восстановления связи; если рабочая версия уже установлена, будет использовать её.

## Файл для поддержки

Если не можете объяснить ошибку, напишите **«Не работает. Подготовь файл для поддержки»**. Получите один ZIP и перешлите сопровождающему Report Kit. Отправка остаётся за вами.

При настройке помощник подготовит в выбранном месте папку **«Поддержка Report Kit»**. Если агент не запускается, откройте её и дважды нажмите **«Подготовить файл поддержки»**. Не требуется искать журналы или вводить команды. Для этого нужны компоненты, которые агент заранее подготовил в папке Report Kit; устанавливать Python самостоятельно не нужно. До завершения подготовки запасной способ может быть недоступен; [справка](HELP.md#не-работает--нужен-файл-для-поддержки) объясняет следующий шаг.

## Начало работы без установки программ для разработчика

Откройте Report Kit в Codex и запустите предлагаемую приложением настройку, если она появится. При первом обращении агент сам проверит, что осталось подготовить, и поведёт дальше. Отдельно просить «помоги настроить» не требуется.

Python и библиотеки вручную устанавливать не нужно. Агент предложит подготовить нужные компоненты в отдельной папке, попросит необходимые разрешения и проверит результат. Если для задачи потребуется отдельный браузер Playwright, агент объяснит причину и предложит подготовить его. Вы входите в аккаунты самостоятельно; пароли и ключи в чат не отправляйте. Настройка продолжится с сохранённого шага. При корпоративном запрете может понадобиться помощь ИТ-службы.
