# Изменения

## 0.1.0-dev.7 — проверка версии обновления

- Предварительная проверка больше не принимает старую или ту же версию как новое обновление, даже при прямом вызове.
- Для возврата к прежнему комплекту остаётся отдельная проверка отката, сохраняющая последующие изменения владельца.
- Проверка всех клиентов и разрешения приложения сохраняются; установка и публикация не выполнялись.

## 0.1.0-dev.4 — сведения о зависимостях

- Добавлены проверенные exact metadata и ограничения среды запуска.
- Для LiveDune нужно проверить Node20 или новее; наличие root package с требованием18 недостаточно.
- Лицензию своего кода выбирает владелец; независимые проверки и испытания устройства ещё не завершены.
- Никакие зависимости не установлены, capture/API код и настройки существующих клиентов не изменены.

## 0.1.0-dev.3 — локальная подготовка

- Подготовка локального черновика из точных коммитов обоих пакетов; архивы проверяются по составу и байтам.
- Заметки выпуска и границы публикации включены в инструкции сопровождающему.
- Существующий клиентский отчёт, доступы и авторизация этой работой не меняются.

Комплект ещё не публичный выпуск. Лицензия, независимые проверки и работа на устройстве сотрудника требуют завершения.

## 0.1.0-dev.2

Добавлены руководство, помощь и readonly проверки полного списка клиентов перед обновлением. Установка и live refresh отдельно не проверены.

## 0.1.0-dev.1

Подготовлен переносимый порядок сопровождения: обращение, исправление и проверенный повтор исходного шага. Служебные маршруты выбираются приватно; автоматический обмен не активирован.

## 0.1.0-dev.0

Первоначальная локальная подготовка двух пакетов для будущих клиентов; чужие аккаунты, сессии и готовые отчёты исключены.


## 0.1.0-dev.5 — Report Kit

Package IDs and portable agent workflow names now use report-kit-. Workspace schema2 rejects old package keys; setup must review a separately prepared configuration, never silently migrate existing data. Source skill IDs and state/queue paths are unchanged. No installed/client rollout, live report or public release implied.


The same uncommitted dev.5 naming slice now includes all12 report source skills and self-contained employee entrypoints. Rules/helpers for template QA, updates, rollback, cleanup and source FIFO are shipped locally; external capabilities still require employee setup. Seven new source exports have no donor sessions/private pilot history.


## 0.1.0-dev.6 — понятное начало работы

Пошаговая настройка и опрос о первом клиенте, понятный выбор формата и источников, самостоятельная разрешённая диагностика и помощь при ограниченных правах. Сотруднику объясняются первый отчёт, отдельная основа и проверка следующего периода. Полный каталог источников отражён в помощи.

Совместимые обновления можно отдельно разрешить один раз с возможностью отзыва. Проверяется неизменный источник/все клиенты; подтверждения приложения и ограничения сохраняются. Это подготовленные инструкции и локальная проверка выбора; на устройстве сотрудника установка, автоактивация и понятность ещё не проверены.
