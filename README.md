# Report Kit

Report Kit помогает готовить клиентские отчёты по образцу. Вы присылаете прошлый отчёт, нужный период и источники данных. Помощник собирает материалы, оформляет результат и учитывает ваши замечания в следующих отчётах.

Можно делать презентации, документы и таблицы в Google. Для статистики и снимков публикаций есть инструменты работы с LiveDune и социальными сетями.

**Это первая тестовая версия.** Настройку на компьютере сотрудника, особенно на Windows, ещё предстоит проверить. [Тестовый выпуск](https://github.com/nikpanaev/report-kit-agent/releases/tag/v0.1.0-dev.33).

## Как начать

Откройте новый чат в Codex и отправьте ссылку на этот репозиторий. Можно написать:

> Хочу готовить отчёты с [Report Kit](https://github.com/nikpanaev/report-kit-agent). Подключи его и помоги настроить работу.

Помощник проверит доступные возможности и задаст необходимые вопросы. Если приложение попросит подтверждение, он объяснит, что разрешить и зачем. Простое открытие страницы на GitHub ничего не устанавливает.

После настройки пришлите образец первого отчёта и укажите месяц и год. Помощник уточнит источники, папку для результата и доступы. Готовый отчёт нужно будет просмотреть и принять.

## Что понадобится

- Codex, в котором помощнику разрешено работать с файлами и подключать нужные сервисы.
- Интернет для первой загрузки и получения данных.
- Образец отчёта, ссылки на источники или файлы с данными.
- Ваши аккаунты в тех сервисах, которые нужны для отчёта.

Python и библиотеки вручную устанавливать не нужно. Помощник подготовит необходимые компоненты после вашего разрешения. Если понадобится Chrome или отдельный браузер для снимков, он предложит его подготовить.

Сервисы подключаются по мере необходимости. Если LiveDune для отчёта не нужен, настраивать его заранее не придётся. Пароли, ключи и коды входа в чат не передаются.

## Что настроит помощник

Он подберёт нужные инструменты, поможет выбрать папку для работы и проверит подключения. Вам не нужно разбираться во втором репозитории или выбирать совместимые версии.

Настройки и выполненные шаги сохраняются. После перезапуска помощник продолжит с незавершённого места. Материалы клиентов хранятся отдельно от файлов Report Kit.

Во время первой настройки можно разрешить совместимые обновления или выбрать подтверждение перед каждым обновлением. Проверка новых выпусков происходит перед работой, не чаще раза в сутки. При закрытом приложении она не выполняется. Новые разрешения и подключения аккаунтов согласуются отдельно.

## Если что-то не работает

Напишите:

> Не работает. Подготовь файл для поддержки.

Помощник соберёт один архив со служебными сведениями и покажет, где он находится. Пересылаете его поддержке вы сами. Содержимое отчётов, ключи и переписки в архив не включаются.

## Что ещё проверяется

Подготовлены варианты для Windows 11 и новее, x64, и macOS 14 и новее на Apple Silicon. Работа на Windows, первая установка, обновление и возврат к прежней версии на компьютере сотрудника пока не подтверждены. [Проверка Windows](docs/WINDOWS-CHECK.md).

Linux, macOS на Intel, Windows ARM и Windows Server этой поставкой пока не поддерживаются. Если приложение или правила компании запрещают необходимое действие, помощник объяснит ограничение и сохранит выполненные шаги.
